# RetailPulse – AI-Powered Customer Analytics & Demand Forecasting Platform

## Project Overview

RetailPulse is an interactive retail analytics dashboard designed to analyze sales performance, understand customer behaviour, forecast future demand, and support inventory planning.

## Key Features

* Sales performance analysis
* Product performance analysis
* Customer analytics
* Monthly sales forecasting
* Prophet 30-day sales forecasting
* Customer segmentation using machine learning
* Inventory optimization
* What-If analysis
* LSTM forecasting
* Forecast model comparison
* Customer churn prediction and risk analysis

## Technologies Used

* Python
* Pandas and NumPy
* Scikit-learn
* Streamlit
* Matplotlib and Plotly
* Prophet
* Machine Learning

## Installation

1. Clone the repository.

2. Install dependencies:

   `pip install -r requirements.txt`

3. Run the dashboard:

   `python -m streamlit run app.py`

## Dataset

The project uses retail transaction data for sales analysis, customer segmentation, demand forecasting, and inventory planning.

## Dashboard

The dashboard is developed using Streamlit and provides interactive charts, filters, predictions, and downloadable CSV reports.
